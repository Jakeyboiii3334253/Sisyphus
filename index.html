Fitness rewards holding the boulder high, not just touching the top once — so a well-trained fly is still fighting a losing, endless battle rather than "solving" the hill. The brain is a small from-scratch neuroevolved network (≈49 weights), not Google/Janelia's real FlyWire fruit-fly connectome — that dataset maps ~140,000 real neurons and needs research-scale compute, far beyond a browser. The page renders with three.js, loaded from a CDN, so it needs an internet connection at runtime — everything else is self-contained and needs no backend, so it deploys as-is on Netlify: drag this folder onto app.netlify.com/drop, or push it to a repo and connect it as a site.
